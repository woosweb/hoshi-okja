# 호시옥자 브랜드 스토리 슬라이드

정적 HTML/CSS/JS로 만든 호시옥자 웹 슬라이드형 랜딩 페이지입니다.

## 실행 방법

별도 설치가 필요 없습니다.

1. `index.html`을 브라우저에서 엽니다.
2. 데스크톱에서는 스크롤 또는 오른쪽 아래 화살표 버튼으로 슬라이드를 이동합니다.
3. 모바일에서는 일반 세로 스크롤 페이지처럼 확인합니다.

## 파일 구조

```text
index.html
styles.css
script.js
assets/
```

- `index.html`: 슬라이드 문구와 이미지 배치
- `styles.css`: 전체 디자인, 반응형 레이아웃, 색상
- `script.js`: 목차 활성화, 이전/다음 이동
- `assets/`: 전체 보드 이미지와 커버용 가로 이미지 자산

## 배포 방법

정적 파일만 있으므로 Netlify, Vercel, GitHub Pages에 그대로 배포할 수 있습니다.

- Netlify: 폴더를 드래그 앤 드롭하거나 Git 저장소를 연결합니다.
- Vercel: 새 프로젝트를 만들고 이 폴더를 연결합니다.
- GitHub Pages: 저장소에 올린 뒤 Pages의 배포 브랜치를 지정합니다.

빌드 명령은 비워두고, 출력 폴더는 프로젝트 루트로 두면 됩니다.

## Google Sites에 연결하는 방법

1. 위 방식 중 하나로 사이트를 배포합니다.
2. 배포된 URL을 복사합니다.
3. Google Sites에서 `삽입` → `임베드` → `URL`을 선택합니다.
4. 배포 URL을 붙여 넣고 페이지에 맞게 크기를 조정합니다.

Google Sites 안에 직접 HTML 파일을 업로드하는 방식보다, 정적 호스팅에 올린 뒤 URL로 연결하는 방식이 안정적입니다.

## 이미지 교체 방법

이미지는 `assets/` 폴더에 있습니다. 같은 파일명으로 새 이미지를 덮어쓰면 HTML 수정 없이 교체됩니다.

주요 이미지:

- `assets/place-story-strip.png`: 커버용 가로 보드
- `assets/final-interior-board.png`: 확정 인테리어 전체 보드
- `assets/final-brand-identity.png`: 확정 로고/패키지/인스타그램 브랜딩 전체 보드

보드 이미지는 원본보다 크게 확대하지 않도록 설정되어 있습니다.

## 인스타 핸들 변경 방법

`index.html`에서 `@hoshi_okja`를 검색해 원하는 계정명으로 바꾸면 됩니다.

## 슬라이드 텍스트 수정 방법

`index.html`의 각 `<section class="slide">`이 한 장의 슬라이드입니다.

문장을 바꿀 때는 한 슬라이드에 하나의 메시지만 남기는 기준을 유지하면 전체 톤이 흐트러지지 않습니다.
